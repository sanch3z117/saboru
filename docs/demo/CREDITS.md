# Créditos de fotos demo — SaborU

Estas imágenes son **solo para el entorno local y la demo**. No representan
locales reales: son fotos genéricas de comida, sin personas, marcas ni fachadas
de restaurantes reales.

- **Fuente:** Unsplash (`images.unsplash.com`).
- **Licencia:** [Unsplash License](https://unsplash.com/license), que permite uso
  comercial y no exige atribución. Se conserva la fuente para trazabilidad.
- **Autoría:** el asset descargado no incluye el nombre del fotógrafo; se cita
  “Unsplash contributor” y el enlace original. No inventar atribuciones.
- **Reemplazo:** sustituye los WebP de `public/demo/` por fotos propias y
  actualiza `scripts/upload-demo-photos.mjs` + este archivo. Las fotos propias
  deben tener permiso explícito del autor.
- **No usar:** fotos de restaurantes reales, logotipos, marcas, personas o
  imágenes de redes sociales sin permiso.
